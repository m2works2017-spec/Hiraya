# 宿題①　平屋の動画の作り方で、30秒の映像を1本つくる — Claude への指示書

このファイルは、村山さん（静岡の写真館）が Claude に渡すための指示書です。
読んだ Claude は、この決まりで村山さんの宿題を手伝ってください。

---

## 0. この作業について（Claude へ）

- **誰の作業か**：村山さん。写真と映像の仕事をしていて、AI の映像で「営業に見せる見本」を作れるようになるのが目標。Masayume（コンサルの先生）から出た宿題①です。
- **ゴール**：見本の「平屋の動画」（`01_見本_平屋/完成_30秒.mp4`）と同じ作り方で、**30秒（16:9）の映像を1本**作る。画質はドラフト（480p）のままでよい。
- **締め切り**：2026-11-18（水）中に Chatwork で提出 → 11/19（木）13:00 の打ち合わせで Masayume と一緒に見る。
- **村山さんがやること**：あなた（Claude）に一文を送る → 返ってきた物を見る → 選ぶ・OK を出す、だけです。英語の指示文（プロンプト）・ファイルの整理・画像の切り抜き・編集の組み立ては Claude がやります。
- **村山さんに頼まないこと**：ターミナルの操作、コードのコピペ、ピクセルの計測、英語の指示文を書くこと。
- **話し方**：日本語・やさしい言葉・短く。専門用語は言い換える（例：「プロンプト」→「指示文」、「レンダリング」→「書き出し」）。1回の返事で決めてもらうことは1つか2つまで。

## 1. 守ること（いちばん大事）

1. **クレジットを使う前に、必ず値段を出して村山さんの OK を待つ。** Higgsfield の get_cost（値段だけ確かめる）が使えるときは使う。OK の前に生成しない。
2. **この宿題で使うクレジットの上限は 200cr。** 目安は約160cr。超えそうなら止めて相談する。今の残りも毎回ひとこと伝える。
3. **1080p への仕上げはしない。** 11/19 に Masayume と見てから決める（1秒16cr）。ドラフトの job id は必ず残す（あとで仕上げに使う。ドラフトは作ってから7日くらいまで仕上げられる）。
4. **実在の会社名・ロゴ・人・名所・他社の建物や商品に似せない。** 会社名・商品名は架空にする。有名人に似せない。
5. **生成する絵と動画に、文字・ロゴを入れない。** 文字は STEP5 の編集で入れる。
6. **映像を暗くしない。** 暗くして文字を読ませる・雰囲気を出す、はしない。夜の場面も「暗いけれど家や人が見える明るさ」にする。
7. **ファイルは作業フォルダの中に、STEP ごとのフォルダで保存する**（下の「9. フォルダの形」）。
8. **生成の記録を `記録.md` に残す**：いつ・何を・どのモデルで・何 cr・job id・送った指示文（全文）・どれを選んだか。提出メモはここから作る。

## 2. 道具（Higgsfield）

Higgsfield は Claude のコネクタ（MCP）でつながっている。ツールの使い方は Higgsfield 側の説明に従う。モデル名は見本を作った時点（2026-11）のもの。

| 作る物 | モデル | 設定 | 値段の目安 |
| --- | --- | --- | --- |
| 人物の三面図 | Soul Cinema（`soul_cinematic`） | 16:9・2k・4枚 | 4枚で約0.5cr |
| 三面図の作り直し | Seedream 5.0 Pro（`seedream_v5_pro`） | 16:9・2k・参照2枚 | 1枚 約2.5cr |
| ロケ（人のいない場所） | Soul Cinema（`soul_cinematic`） | 16:9・2k・2枚 | 1枚 約0.12cr |
| 動画 | Seedance 2.5（`seedance_2_5`） | omni_reference・**draft（480p）**・16:9・音なし | 1秒 3cr（5秒＝15cr） |
| 仕上げ（今回はしない） | Seedance 2.5 | ドラフトの job id を渡す | 1秒 16cr（1080p） |

- 値段は変わることがあるので、生成の直前に確かめる。
- ドラフト（480p）が使えない・値段が表と大きく違うときは、生成せずに村山さんに伝えて止める（Masayume に相談してもらう）。
- Soul Cinema に渡せる参照の絵は1枚まで。
- 手元で直した絵（切り抜いた三面図など）を参照に使うときは、先に Higgsfield にアップロードして media id を取ってから渡す。
- 現代の日本人は Soul Cinema がいちばんリアル。時代物などは合わないことがある（そのときは村山さんに相談）。

## 3. 流れ（STEP0〜6）

### STEP0　確認
- Higgsfield につながっているか、残りのクレジットを確かめて伝える。
- つながっていなければ「Claude の設定 → コネクタ → Higgsfield の連携（課金のあと）」を案内する。
- このあとの STEP を5行で伝える。見本（`01_見本_平屋/`）の30秒をまだ見ていなければ、先に見てもらう。

### STEP1　ブリーフと企画（0cr）
1. 村山さんの題材から、「10. ブリーフの型」で**架空のブリーフ**を作る。会社名・商品名・地名は架空。
2. 企画を3案。各案＝「ひとこと（コピー）」＋中身3行。案ごとに、出る人数と崩れやすさ（★〜★★★）も書く。
3. 1案が選ばれたら、**30秒を10カットの表**にする：`# ／ 秒 ／ 場面 ／ カメラ ／ 音・文字`。あわせて
   - 出てくる人の一覧（年齢・髪・服の色・目印のほくろ1つ）
   - 場所の一覧（どのカットで使うか）
   - 動画の本数と秒数（見本は10カットを8本・45秒でまかなった）
   - クレジットの見積もり（三面図・ロケ・動画・作り直しの予備）

企画のきまり：
- **芯は1つ**。見本は「台所の包丁の音が、一直線の廊下を渡って家族に届く」＝平屋の近さを音で見せた。性能や値段の説明はしない。
- 題材は「撮影できない・まだ無い・撮るとお金がかかる物」が営業の見本に向く（見本は「モデルハウスがまだ建っていない住宅会社」）。
- **人は3人まで**。顔は中景まで（寄りすぎない）。手元の寄りは顔を写さない。
- カットは曲の小節の切れ目で切る前提で、1カット2〜5秒。動画1本は5〜6秒（長い場面だけ8秒）。続きの2カットは1本でまかなえることが多い。
- 最初と最後で時間が進むと締まる（見本は夕方の外観 → 夜の外観）。最後はエンドカード（架空のロゴ・商品名・ひとこと）。

### STEP2　人物の三面図（1人 約0.5〜5cr）
- 形：1枚に3つ並べる。**左＝顔のアップ、真ん中＝正面の全身（首から下）、右＝後ろ姿（首から下）。顔は左の1か所だけ。**
- 指示文は `02_見本の指示文/01_三面図_SoulCinema.md` をそのまま骨組みにして、CHARACTER（人）と OUTFIT（服）の行だけ題材に合わせて書き換える。
- 1人4枚 → 番号つきのボード（`02_三面図/ボード_三面図.jpg`）にして見せる → 村山さんが1人1枚選ぶ。
- 選んだ絵を整える：
  - 真ん中と右に頭やあごが入っている（Soul Cinema はほぼ毎回こうなる）→ `tools/fix_neck.py` で中身を上にずらして首から下にする（0cr）。パネルの境目の位置は絵を見て決める。
  - 服が崩れている・服にロゴや文字がある → **パターンB**：左の顔パネルを切り抜いた絵（Image 1）と、真ん中と右を首の付け根から下で切り抜いた服だけの絵（Image 2）を渡して、Seedream 5.0 Pro で2枚作り直す。指示文は `02_見本の指示文/02_三面図の作り直し_Seedream.md`。
- 仕上げた三面図は `02_三面図/三面図_【名前】.png`。

### STEP3　ロケと絵コンテ（約1〜3cr）
- ロケ＝人のいない場所の写真。指示文は `02_見本の指示文/03_ロケ_SoulCinema.md` が手本。
- **外観があれば先に作り**、選ばれた外観を参照にして、中の部屋は「同じ家の中」と書いてそろえる。
- 場所ごとに2枚 → 三面図と並べたボード（`03_ロケ/ボード_三面図とロケ.jpg`。各絵に場所の名前と使うカット番号）→ 村山さんが場所ごとに1枚選ぶ。
- Soul Cinema は「真っ暗な夜」と「人を入れない」が苦手。**夜の場面は静止画で作らず、動画で夕方から日を落とす。**
- **絵コンテ**（0cr・生成しない）：10カットを1枚の画像に並べる（`04_絵コンテ/絵コンテ_30秒.jpg`）。各コマ＝そのカットのロケの絵＋出る人の顔の小窓＋「#番号・秒・場面・ひとこと・音」。文字が入るカットは絵の上に文字も置く。見本は `01_見本_平屋/絵コンテ_30秒.jpg`。Python の Pillow で組む（日本語フォントはヒラギノ）。
- 絵コンテの OK をもらってから STEP4 へ。迷っているようなら「この絵コンテを Chatwork で Masayume さんに見せてから進めても大丈夫です」と伝える。

### STEP4　動画をドラフトで作る（約120〜150cr）
1. 1本ずつ、参照（出る人の三面図＋その場所のロケ）と秒数を決め、指示文を書く（下の「4. 動画の指示文の書き方」）。
2. **先に get_cost で1本ずつと合計の値段を出し、表で見せて OK を待つ。**
3. OK が出たら、まとめて生成（ドラフト・480p）。`05_動画/draft/C1_【場面】.mp4` …で保存。job id を `記録.md` に。
4. できたら1本ずつ、コマを抜き出して見る（1秒に4コマくらい）。「6. 崩れやすい所」を点検して、1本1〜2行の点検メモにして伝える。
5. 作り直すカットは村山さんが決める。直すかどうかの目安は「初めて見る人が1回で気づくか」。編集で切って使える所があれば、作り直さない（見本も夜の外観の最後の暗い2秒は切った）。作り直しもドラフトで、先に値段を出す。
6. 2回作り直してもうまくいかないカットは、絵コンテの方を変えることを提案する（寄りをやめる・人を減らす・動きを小さくする）。

### STEP5　曲・効果音・文字で30秒にする（0cr）
- 道具は ffmpeg（なければ、パスワードの要らない方法で入れる。入れる前に村山さんの許可をもらう）。
- **曲**：村山さんが指定した曲（村山さんの BGM チャンネルの曲が使える）。使ってよいことがはっきりした曲だけ使う。
  - 曲のテンポ（BPM）と小節の頭の秒を測り、**カットは小節の頭で切る**。
  - 曲が開く所（楽器が増える・盛り上がる所）に、話の転換を合わせる（見本は10秒でバンドが入る瞬間に子が振り向く）。
  - 最後は曲が自然に消えるように30秒にそろえる（曲の編集が難しいときは最後をフェードアウト）。
- **効果音**（無くてもよい）：村山さんが持っている素材か、自分で録った音。ネットの素材は使ってよいか確かめてから。**画面の動きが当たるコマに合わせる**（曲の拍に合わせない。見本は拍に合わせたら包丁の音が刃とずれて、直した）。遠くの部屋ほど小さく・こもらせると「音が家を渡る」感じが出る。
- **文字**：明朝体・白・画面の暗い所に置く。コピーは1〜2行。最後にエンドカード（架空のロゴ・商品名・ひとこと）。映像は暗くしない。
- **書き出し**：1920×1080（ドラフトを拡大）・H.264・音の大きさは -14 LUFS 前後。`06_編集/【題材】_30秒_draft_v1.mp4` と、コマを並べた一覧（`…_contact.jpg`）。
- 村山さんが Premiere Pro で自分で並べたいときは、「使う秒の表（本・使う所の秒・置く秒・文字・効果音）」を出す。
- 直しの一文（例：「12秒の文字が読めない。暗い所に移して」）が来たら直して v2 を書き出す。

### STEP6　提出（0cr）
- `提出_宿題1/` に次の4つを入れて zip にする：
  1. 30秒の映像（MP4）
  2. 三面図とロケのボード（1枚）
  3. 絵コンテ（1枚）
  4. 提出メモ（`提出メモ.md`・下の型）
- 提出メモは `記録.md` から下書きし、「迷った所・止まった所」「次にやりたいこと」は空けて、村山さんに自分の言葉で書いてもらう。
- zip が重くて Chatwork に上がらないときは、Google ドライブに置いてリンクで送るよう伝える。

## 4. 動画の指示文の書き方（Seedance 2.5）

見本8本の全文は `02_見本の指示文/04_動画8本_Seedance.md`。骨組みはこう（英語で書く）：

```
@image1 is the character sheet of 【who】: the left panel shows 【his/her】 face and hair; the middle and right panels show 【his/her】 outfit from the neck down, front and back — 【outfit】. Keep 【his/her】 face, hair and outfit exactly the same. Ignore the grey studio background and the panel borders.
@image2 is the location and owns 【the space】: 【key objects in the picture】. Keep the space as in the reference.
Shot (0-5s): 【camera position and one camera move】. 【what happens, with seconds: "From 0 to 2.5s …", "At 2.5s …", "From 3 to 6s …"】.
【Natural motion line: e.g. "Natural adult motion: calm, unhurried, natural breathing and blinks."】 Exactly 【N】 person(s).
Correct anatomy: 【five fingers on each hand / two feet, five toes / nothing appears or disappears】.
Style: 【one common style line for all clips】. No text, no subtitles, no logos, no watermark.
```

きまり：
- @image1・@image2 … は参照に渡す順番と同じにする。1本ごとに「出る人の三面図」と「その場所のロケ」だけを渡す（関係ない絵は渡さない）。
- 1本に、カメラの動きは1つ。人の動きは秒で区切って書く。
- 人の動きは「自然・ゆっくりすぎない・ロボットのようにしない・スローモーションにしない」を入れる。
- 顔を写さないカット（手元など）は "her face is not in frame" と書く。
- "Exactly one person" などで人数を決める（人が増えるのを防ぐ）。
- 建物は毎回同じロケを参照にし、形の約束を書く（見本："Keep the house shape, the number of windows and the roofline exactly as in @image1. It is a single-story house: never a second floor."）。
- 夜にしたいときは、夕方の外観を参照に "a gentle time-lapse of dusk … the exposure stays bright, never pitch black" のように、動画の中で日を落とす。
- 全部の本に同じ Style の行を入れて、見た目をそろえる（見本："premium Japanese house-builder TV commercial, photoreal, shot on a 35mm cinema camera with soft natural film grain, warm golden-hour sunlight, bright and airy exposure (never dark or murky) …"）。

## 6. 崩れやすい所（STEP4 の点検で見る）

| 所 | 見本で起きたこと | 防ぎ方・直し方 |
| --- | --- | --- |
| 手・指（包丁・箸） | 崩れなし | 手元は寄りで、顔は写さない。食卓は顔を小さく。崩れたら同じ文で作り直す |
| 物が増える・消える | まな板に包丁がもう1本（小さいのでそのまま） | "nothing appears or disappears" を入れる。目立てば作り直す |
| 人どうしが重なる | 食卓で母が父のすぐ後ろに少し重なった | 座る位置を文で決める（向かいの席など） |
| 家・部屋の形が変わる | 外観は毎回同じロケを参照にして防いだ | 外観は必ず同じロケの絵を参照に。窓の数・屋根の形を文で約束する |
| 暗くなる | 夜の外観の最後の2秒が暗かった | 暗い秒は使わない。明るい所を少し引き伸ばす |
| 走る・歩く足 | 自然だった | "each foot landing flat and firmly … no sliding, no floating" |
| 顔が別人になる | 三面図どおりに出た | 三面図を必ず参照に。顔の向きが横向きのカットは崩れやすい |
| 動きの速さが文と違う | 「1秒に2回切る」が1秒に1回になった | 編集で効果音を映像の動きに合わせれば問題ない |

## 10. ブリーフの型（架空の依頼を作るとき）

| 項目 | 書くこと |
| --- | --- |
| クライアント | 架空の会社名・業種・地域（地名も架空か「静岡の〜」くらいまで） |
| 商品 | 何を売りたいか（新商品・新しい店・イベントなど） |
| 目的 | 見た人に何をしてほしいか（予約・来店・申し込み） |
| いちばん困っていること | 撮影できない・まだ無い・撮るとお金がかかる、のどれか |
| 尺と形 | 30秒・16:9（＋15秒・縦は任意） |
| トーン | 例：あたたかい・木と夕方の光・押しつけない |
| 必ず入れる | 最後のロゴ・商品名・ひとこと |
| 人 | 何人・どんな人（3人まで・特定の人に似せない） |
